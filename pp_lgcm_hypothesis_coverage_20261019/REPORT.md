## 2. 为什么这些成果仍不等于原任务完成

已重新读取20260214原稿`word/document.xml`，原DOCX SHA-256保持`0fffe9e24b480bd35c700399c3a4961589f71a304637d7fca5c76eb6ce97d870`。本包只摘录可见文字，排除Zotero字段指令；段落编号是XML正文直接子段落从0计数，不是页码。

原稿第114段登记了五条时间路径，分四个子模型：

| 子模型 | 原稿路径 | 当前CHARLS观测基期路线能覆盖什么 |
|---|---|---|
| M1 | IX×IZ→IY，以及IX×IZ→SY | 当前四家族没有把这两条完整潜变量路径纳入估计 |
| M2 | IX×SZ→SY | 观测Z₀没有提供潜在变化SZ，不能用替代路线宣称完成 |
| M3 | SX×IZ→SY | 已有SX×观测Z₀敏感性；Z₀与利用多期估计的IZ不同 |
| M4 | SX×SZ→SY | 当前观测Z₀路线没有估计这条路径 |

四类指标×五条路径形成20个估计对象位置，详见`ORIGINAL_FIVE_PATH_COVERAGE.csv`。这是解释覆盖的映射，不是重新要求执行全部历史规格或把历史连续／中位数组模型重复计数。原稿第80、115段还说明采用过因子得分近似，第119段集中强调M3的四项二分调节；修正后的完整潜变量路线、历史因子得分路线、观测基期敏感性是三种不同证据。

第35—36段的两项镜像假设也不能只靠交换“自变量／调节变量”标签补齐。同一个乘积项可以从两个条件关系角度解释，但SX×Z₀不能被改名为IX×SZ或SX×SZ。研究问题中“起点”和“变化”的角色必须与实际模型一致。

H4.1a/b的原文（第43—44段）讨论资源对家内差异关联的竞争性预测。当前基期Z₀家族只覆盖基期差异的条件关联异质性；总体均值三个家族补充积极关系的资源组差。二者均不自动完成家内差异变化轨迹的全部直接关联异质性。

H4.2a/b（第45—46段）讨论资源对关系互动的再调节。当前12项提供观测基期Z₀工作路线的正式组差，但完整潜在IZ/SZ路线没有由此变成已完成。第39—40段的父母性别异质性H3也不能用教育、城乡、收入结果替代；本轮仅记录其边界，不自动追加性别队列。

## 3. CFPS与CHARLS仍开放的具体问题

| 范围 | 当前事实 | 正确处置 |
|---|---|---|
| CFPS基期Z₀×资源H4.1 | 12个登记规格中3个完整十份条件家族；其余7个首份不可采用、2个在MI02停止 | 保存负方差及完整成员记录，不选取成功子集，不原样重跑 |
| CFPS完整四项调节／H4.2 | 当前修正后没有完整可采用推断 | 已收尾稿和新探索分开；不恢复原有阈值、机制或H4支持主张 |
| CHARLS四类潜在Z轨迹调节 | 四个三过程无交互父模型可采用；四个交互240秒超时，0个完整MI家族 | 超时不等于无效应，也不证明理论不可识别 |
| CHARLS SD低积分点校准 | q15、4核首候选仍真实计算超时；后续起点／精度校准没有准入 | 保留停止规则，未用额度不授权依赖模型继续 |

CFPS收入分组是“是否有正个人收入”，当前CHARLS是基期家庭净收入超过固定8730元的分组；不能合称同一种高／低资源测量。CHARLS测量子女见面频率，CFPS测量情感亲近度；CHARLS使用绝对SD及有符号差，不能直接套用CFPS相对差异解释。亲近度总体均值模型的当前CHARLS队列N=2983，四类基期差异范围N=2744／2170／2528／2386；潜在Z可行性范围又不同。不能把样本变化导致的系数差异归因于某一个模型修正。

基期控制、结构性无对比、工作FCS、观测值保留及X/Y的FIML缺失掩码已在各原包核验；这些工程和链混合证据不证明MAR或精确实质模型相容。模型含x1/y1对Z₀等路径时，Z₀到潜截距的系数也不是对实测基期结果的全部关联。

## 4. 后续执行顺序

1. **停止重复已有成功家族、旧来源结果和无新依据的失败CFPS。** 本包提供固定来源和覆盖表，后续直接使用。无需新NLM或重新修改冻结稿。
2. **先解决潜在交互的可观察性。** 已证实Windows MplusAutomation的`system(intern=TRUE,wait=TRUE)`缓冲屏幕输出；已有超时因此缺少完整TECH8过程。应先在一个隔离合成例中验证实时stdout保全与有界退出，再判断新的计算试验是否有依据。不得为取日志重跑旧失败CFPS/CHARLS估计，不把日志工具成功当科学完成。
3. **只有出现具体数值或模型依据，才登记新的CHARLS潜在路线小批次。** 先证明一个完整样本候选能获得合法、稳定且积分精度可接受的解，再决定是否准备与该估计对象对应的MI。保留当前q30/p1、q15/p4失败；不自动增加原240秒限额、固定负方差或把低FMI外推到未运行模型。
4. **CFPS剩余H4需不同的科学依据。** 先利用已有输出定位参数边界与样本信息，不能仅换标签、提高迭代次数或为了显著性扩展规格。若没有可辩护的新方案，应明确未能形成推断，而不是无限自动运行。

当前没有新模型合同已获准入，也没有后台模型队列在等待本包。上述顺序是依赖安排，不是声明已完成未来测试。
