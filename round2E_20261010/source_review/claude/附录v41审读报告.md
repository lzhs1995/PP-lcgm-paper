## 二、需要修改的地方

### 1. 附表 A9 的失败原因笼统，且老大差 D0 的描述与事实不符（p6—p7）
- A9 对四个 D0 一律写"已执行成员在有限起点核查后仍不合法；后续成员未执行"。但老大差（OLDEST）D0 已执行六份，前五份合法（USABLE），只有第六份及其修复不合法（MODEL_EXECUTION.csv、D0_VARIANCE_DIAGNOSTICS.csv）。
- 复核意见第四节已要求区分负方差、求逆失败、鞍点和超时。建议按以下事实逐行改写（数值取自包内文件）：

| 分支 | 规格 | 实际情况 |
|---|---|---|
| 标准差 | D0 | MI01 两次尝试 SY 条件残差 −0.132（SE 0.322，z≈−0.41），其余不违规 |
| 性别差 | D0 | MI01 SX −0.144（SE 0.289）与 SY −0.154（SE 0.229）同时为负 |
| 老大差 | D0 | MI01—05 合法；MI06 与修复 SY −0.00057/−0.00069（SE 0.137，z≈−0.005）；不能丢弃 MI06 后合并前五份 |
| 长子差 | D0 | MI01 两次尝试 SY −0.285（SE 0.546，z≈−0.52） |
| 标准差 | D1 | MI01 在第523次迭代 estimated covariance 不可求逆，估计未完成 |
| 性别差 | D1 | MI01 首次不合法；修复在第711次迭代不可求逆 |
| 老大差 | D1 | MI01 首次超时（6小时）；纯 EM 修复正常结束，但有鞍点、SY −0.528 及参数协方差问题 |
| 长子差 | D1 | MI01 首次不合法；修复 21608.9 秒超时 |

- 另外，"estimated covariance 不可求逆"不应统称为 Hessian 或信息矩阵不可求逆（复核意见第四节）。
- 新增诊断：全部 D0 负方差的 est/SE 都在 −0.7 以内，属于"接近零的边界"，不是显著的负方差。Round 2E 据此预登记了 SY 边界规则和 D0B（sy@0）诊断，A9 可加注："负值不显著，Round 2E 以预登记边界家族处理，不删成员、不混合规格"。

### 2. 附表 A10 的标题和首句会被误读为 SW 也不可报告（p8）

### 3. 附表 A11：参考点改为实际支持点（p8）
- "三参考值事前固定为 −1、0、1"。对 SD，原始零对应 z = −0.4759，z = −1 在数学上不可能出现。Round 2E 改为由本机数据在估计前生成 `SUPPORT_POINTS.csv`：原始零点、两侧非零值中位数（占比≥5%）、P10/P90（与零点不重合时），同时报告观测最小值和最大值。

### 4. 附表 A12：按成分绑定 H4.2a/b（p8）
- "两组同向且差异显示幅度较大/较小，才分别支持 H4.2b/H4.2a 方向"没有说明是哪一成分。同理见正文报告第二节第1条。
