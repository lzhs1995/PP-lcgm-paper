# CFPS moderation readback

This is a read-only audit of existing Mplus `.out` files performed through the
live RStudio/ClaudeR session. It does not start Mplus, alter the six canonical
R scripts, or overwrite the historical result tree.

The reproducible R entry point is `work/cfps_moderation_readback_20261004.R`.
The selected files include multiple filename/specification variants, so the
p-value counts are an inventory, not a model-selection or scientific-acceptance
decision. Interpretation remains subject to the CFPS MI, LRT, convergence,
parameter-boundary, and manuscript-provenance gates.
