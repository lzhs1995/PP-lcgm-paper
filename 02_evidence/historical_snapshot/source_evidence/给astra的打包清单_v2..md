| 编号 | 内容 |

| T2 | 2016 年长短版比较：在 2016 年当年面访、年龄 ≥ 60 岁的全部受访者中（不按以后是否在访筛选），按问卷版本（长版 CESD20 / 短版 CESD8）分组，给出同 8 题总分的人数、均值、标准差；再在分析样本内做同样比较。若找不到官方版本标记，写明用什么方法识别（例如是否回答了另外 12 题），并注明"非官方标记"。 |
| T3 | CESD8 逐题均值（8 题 × 5 期）；两道正向题（"我感到愉快""我生活快乐"）在各期的编码方向。 |
| T4 | 若数据中同时有 8–32 和 0–24 两种计分：二者之差不等于 8 的记录数（按年份）。 |
| T5 | 2012 年观测到的家内结构（各模型自己的样本内）：标准差 = 0 的比例；性别差 < 0 / = 0 / > 0 的比例；排行差（老大、长子）< 0 / = 0 / > 0 的比例；各自的均值、标准差和四分位数。 |
| T6 | 因子得分的中位数切点：I2、I3、I4、I4_4 因子得分的中位数、恰好等于中位数的人数、高低两组人数；以及与 T5 中 2012 年观测类别的交叉表。 |
| T7 | 抑郁数据的缺失模式：每人有几期数据的分布；2012 年后失访与死亡的人数（能区分时）。 |
