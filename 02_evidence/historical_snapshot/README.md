# PP-LGCM CFPS 七项审阅审计包

日期：2026-10-05。CFPS全量复现与论文表图来源对应已完成；本包服务于随后的论文意见处理，CHARLS按用户指令暂停。

本轮基线为正文v42与附录v36，隔离修订为正文v43和附录v37。主分析量尺为CESD8；CESD20实际或官方等化分仅用于敏感性。原始数据、六份R、原始Mplus和原DOCX未覆盖。

## 阅读顺序

1. `OPINION_DECISIONS.md`及`opinion_decisions.csv`：七项意见的19个细分议题及证据位置。
2. `summaries/`：T1—T7、测量审计、因子得分切点和不确定性；`sensitivity_current_status.csv`是本轮八个预定规格的最新终态，`sensitivity_all_attempts.csv`保留输入格式错误在内的全部12次尝试。
3. `model_index.csv`：复用的747条表格来源索引，记录不等于唯一模型数。`model_details.csv`补充优先材料的语法、插补、诊断和包内位置；`mplus/<输出哈希前12位>/`保存完整原始`.inp/.out`。
4. `existing_evidence/`：既有调节读回、25项模型比较与语义表格审计；历史证据不能自动升级为当前科学结论。
5. `R_sources/`保留六份原始R，`review_scripts/`为本轮隔离补验脚本；`source_evidence/`含官方量表文件及来源哈希。

## 核心结论与采用边界

- 五期共同CESD8逐人重建及缺失模式与修正数据一致；8—32与0—24恒差8。2016年官方CESD20sc在5304份完整长卷中与实际20—80总分完全一致，敏感性统一减20。
- 2016年长短版为额外12题推断，未找到官方分配标记，不宣称已验证随机分配。
- 原3274人CESD8有效波数2/3/4/5分别928/1070/707/569；报告死亡328人、明确年份326人，不把未知状态当健在。
- 本轮单变量共同样本2225人，协变量完整的直接关联子样本1981人。八个规格中3个出现负方差、2个未收敛、3个正常终止且未检出上述诊断问题。后三者拟合仍有分歧，不能宣称全套稳健。
- 四项关联模型首轮输入格式被拒；修复90列行宽和参数标签语法后执行，数据哈希相同，统计规格不变。12次引擎调用不等于12个不同科学模型。
- CESD8五期基准不可接受，因此不在其上追加四项核心交互；没有重跑全部旧模型、CHARLS或Bayes队列。
- 25项MI模型比较和必要协方差的正式推断仍有开放项。不能平均P值，不能把组内显著性差异当作组间差异。
