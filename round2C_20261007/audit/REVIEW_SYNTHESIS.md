# Round2C：两份外部建议的本机裁定

本轮交付范围为用户确认的检查点 C。统计结果另见本批结果表；本文件记录运行前的方案裁定，不预告任何模型结果。

## 共识与已关闭的问题

复用 Round2B 十份家庭—个人分层插补；不重做 CESD 计分、家庭共同值修复或得分 SE 导出。新分析入口仍逐份核对数据和原输入 SHA-256。计分修复、基期来源修复和插补数据完整性，不等同于增长模型和调节推断全部有效。

两位评审均正确指出：良好的 CFI/RMSEA、正常结束和 TECH3 可读取，均不能使不合法的潜变量协方差分解合法。固定 SY 条件残差为零是有明确限制的工作模型，不能被描述为所有人抑郁变化相同。

## 分歧的裁定

| 外部建议 | 本轮处理 | 理由 |
|---|---|---|
| ChatGPT：双线性作为有限增长形状对照 | 保留 XLIN，全部十份 | 可检验自由形状是否影响联合变化分解；不保证线性更合适 |
| Claude：同期残差关联更值得优先检查 | 保留 SW，全部十份 | 既有局部失配支持检查，但“遗漏同期共变是唯一原因”尚未被识别 |
| Claude：用 MI01 挑选模型，再扩到十份 | 不采用；三类均跑十份 | 非法父模型的低 FMI 不能保证新结构在全部成员上同样合法，也不能证明 MI 与 FIML 等价 |
| 用对非法父模型的普通或校正 LRT 选择结构 | 不采用 | 非法参照解不能自动支持常规嵌套检验推断 |
| 用 TRd<3.84 选择“相容”剖面点 | 不采用 | 本轮剖面为固定工作假设的敏感性诊断，不构成置信集合 |
| 剖面网格追加与逐项清零 | 不采用 | 固定为 0、.02、.08、.20、.40；不扩展 SWEQ、SW_SY0 或 SX 零方差模型 |
| 全部区间不含零且同号才称方向一致 | 不采用 | 点估计方向、幅度变化和区间不确定性分别报告，不以显著性替代方向判断 |
| 斜率方差 z<2 一律判交互精度不足 | 不采用 | 不能以一个方差的 Wald 比值预判未估计交互的精度；本轮不估交互 |

## 本机独立代数核对

对前批高精度参数重建有向回归矩阵及其残差协方差。MI01 给定控制和两个截距后的 SX 方差约 .110325876、SY 方差约 .012827431、协方差约 −.095434390，代数偏比值约 −2.536859；回代创新方差约 −.069725484。十份重建与原 SY 残差的最大差为 2.78×10⁻¹⁷。详见 `original_parent_geometry.csv`。

这验证了外部评审的算术，揭示相同不合法分解的不同表达；不将它计为独立统计证据，不当作经验相关或效应量。十份插补也不是十次独立调查。

## 合并与停止规则

C1、SW、XLIN 分别完整运行十份；只对全部成员合法且 MI01 不同起点稳定的模型族，独立合并四条预定路径。固定参数不进入自由参数向量，不补造 SE 或 P 值。合并采用参数估计和对应 TECH3 协方差，使用大样本完整数据自由度近似下的 Rubin 推断。

合法性检查包含自由负方差、PSI/G/THETA/SIGMA 几何、预期秩、参数顺序、SE 与协方差对角线对应及识别警告。预先固定零产生的零特征值可以接受；负方差转移、新的秩亏或信息矩阵问题不能放行。不投影矩阵。

本轮共 34 次基础调用、最多 3 次起点核查与 3 次必要修复，总上限 40。完成后无论显著与否均交付；不启动调节、H4.2b、窗口、新 MI 或 bootstrap。主效应是否显著从来不是未来调节的准入条件。
