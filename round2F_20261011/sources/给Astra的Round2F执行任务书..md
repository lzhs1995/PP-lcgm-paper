## 0. 一页结论

**这一轮做什么。** 只做 SD 分支。先用同一积分精度（20 点）和更严的收敛准则，把"积分与收敛近似"与"SY 残差固定为 0"两件事分开；再按事前写定的规则决定完成哪一个十份家族；最后做四组诊断。最多 39 次 Mplus 调用，引擎 3 小时、墙钟 4 小时（引擎按扣除待机后的有效秒计）。预计实际约 1.5 至 2.5 小时。

**为什么这样做。** Round2E 的 SD 自由 E1 在 15 点积分下 SY 残差为 −0.003（SE 0.155），而合法的 E1B 是 20 点积分；两者同时改变了约束和积分精度，不能比较。更重要的是，复核发现所有 CFPS 观测 LMS 调用都在默认 EM 准则（对数似然绝对变化 < 0.001）处停止，按实测衰减比约 0.91 推算，停止时还有约 0.01 的对数似然没有收敛完；而自由 E1 与 E1B 的 LL 差只有 0.004，落在这个误差范围以内。所以先收紧收敛准则，再谈哪个规格可用。

**不做的事。** H4（用户已决定延后）；老大差、长子差整族固定零（需单独批准，见第 11 节）；性别差（SX、SY 同时为负，不加 `sx@0`）；潜 IZ；窗口、量尺、Y 形状；E0B 家族；处理器配对。

**七项意见。** 问题 2 关闭；问题 1、3、4、6 部分解决；问题 5 大部分已改，还有 13 处具体修改（正文 7 处、附录 6 处）；问题 7 方向映射已改正，检验按用户选择延后。详见第 2 节。

**需要补充的数据。** 不需要。可选：Zhang & Liu（2024）第 3871 页或全文 PDF，用于关闭最后一条文献出处核对。

**ChatGPT 方案。** 方向正确，大部分采纳；改动四处（30/40 点改为 20 点严格收敛加精确似然核对；单次时限放宽并按有效秒计；F5 加一个 0.034 点；去掉 E0B 家族和处理器配对）；补充三项（收敛准则冒烟验证、SE 来源分解、Z0 顶端截尾诊断）。ChatGPT 提到的执行包 zip 和 `tools/conditional_gaussian_check.py` 没有随附件到达；本包的 `r2f_exact_ll.py` 是按同一代数独立写的核对器，已用合成数据和蒙特卡洛积分验证。

## 3. Astra 的执行与 Round2E 任务书的对照

**Astra 有理由改动、我接受的部分：**

- 没有采用"负方差不显著即整族自动固定零"的规则。我的 Round2E 任务书把 BOUNDARY_SY 设为自动进入 B2 边界家族，这确实会把"一个样本估计不显著为负"当成"总体为零"，Astra 拒绝它是对的。
- 没有把"替代起点失败"（ALT_FAILED）算作通过。我原来的表把它列为通过，这会把未复现当成稳定，Astra 的判断更稳妥。
- 没有用不合法的 D0 计算 Z0 信度。
- 用按语义键的全参数映射代替 SVALUES 文本拼接，并逐槽记录（4015 个起点槽）。这是改进。
- 34 次调用就按停止规则结束，没有为凑结果而加跑。

**执行中的问题：**

- 1 核与 4 核配对没有触发，因为前提（SD E1 MI01 在 15 点合法）不成立。这是规则的正常结果，不是遗漏。
- 保持唤醒只覆盖了文稿导出和上传，没有覆盖估计监督器。性别差修复调用墙钟 2002.5 秒，其中 1609 秒与系统待机（04:02:09—04:28:58）重叠（`evidence/TIMELINE_POWER_round2E.csv`、`evidence/STANDBY_WINDOWS_round2E.csv`）。另外，04:29—04:53 之间还有三段现代待机，约 20 次调用与之重叠，但这些调用的 CPU 时间约等于墙钟，属于正常计算。
- 性别差的超时不能只归因于待机。首次尝试有 Fisher 信息矩阵病态警告（条件数 0.430D-10，第 111 个参数 SY ON C19）；修复调用在待机前已计算约 393 秒、373 次 EM 迭代，LL 停滞，导数约 0.11。即使没有待机，它也很可能不会正常收敛。

**我原任务书的缺陷：**

- 15 点首试不合法之后，没有安排同节点（20 点）的起点核查，于是自由 E1 只有 15 点结果，E1B 只有 20 点结果，约束与积分被混在一起。ChatGPT 也指出了这一点。
- 没有考虑 EM 收敛准则本身的精度。默认准则下 LL 的剩余误差（约 0.01）与我设的起点容差（LL 差 ≤ 0.01）同量级，这个容差在默认准则下几乎没有判别力。

## 6. Round2F 方案

### 6.1 固定事项（不要改）

- 估计对象：SW 双过程工作模型中，观测 2012 年 Z0 对 SX→SY 路径的调节（SD 分支）。不是潜 IZ 调节，不是因果效应。
- 主插补：Round2E 使用的十份家庭—个人 MI，只读复用，按合同逐份核对哈希。
- 控制：24 列（c1—c24）；wave 不进控制；sat12 不用。
- 结局：CESD8。只做 SX×Z0。
- 样本：SD 3274 人、2410 户。
- 支持点：沿用 Round2E `SUPPORT_POINTS.csv`，原始零 −0.4759262086、正值中位数 1.0667235142、P90 1.2209885637；P0 核对与 Round2E 一致。

### 6.2 模型

LMS 模型：`TYPE = COMPLEX RANDOM; ESTIMATOR = MLR; ALGORITHM = INTEGRATION; INTEGRATION = 20; CLUSTER = fid`；E0 为 `TYPE = COMPLEX`。其余设置（`COVERAGE=.005; ITERATIONS=2000; MITERATIONS=4000;`、单核）与 Round2E 相同；默认准则、聚类设置下生成的输入与 Round2E 逐行相同（自检核对）。N2 只改估计量与是否聚类。

| 代号 | 在 SW 之上增加的语句 | 本轮用途 |
|---|---|---|
| E0 | `ix sx ON z0;` `iy ON z0 (gi0);` `sy ON z0 (gs0);` `x1 y1 ON z0;` | 只在 F6 完整控制样本上估计一次 |
| E1 | E0 + `sxz \| sx XWITH z0;` `sy ON sxz (dc);`，SY 残差自由 | F2；决定 A/A1 时为主规格 |
| E1B | E1 + `sy@0;` | F1；决定 A 时为敏感性，决定 B 时为强约束家族 |
| E1F020 / E1F034 / E1F080 | E1 + `sy@0.020;` / `sy@0.034;` / `sy@0.080;` | F5，单份敏感性；不是总体方差的区间 |

E1B 固定的是 SY 在给定 IX、SX、IY、Z0、SX×Z0 与控制之后的条件残差，不是 SY 的总方差。它意味着这些量给定后 SY 不再有额外的个体随机差异，是很强的工作限制。

收敛准则：所有 LMS 调用加 `LOGCRITERION=0.00001; RLOGCRITERION=0.000000001;`（冒烟测试确认生效后才使用；否则用后备 `LOGCRITERION=0.00001;`）。读回时核对输出中打印的准则；与请求不符记为 `CRITERIA_NOT_APPLIED`，不可用。

### 6.3 起点

- 沿用 Round2E 的语义全参数映射（`r2e_local.R` 原样复用，合同核对哈希）。
- 从 E1B 回到自由 E1（F2a）时，SY 残差是新释放的自由参数，用合同写定的正起点 0.02（`allowed_start_override`），其余全部参数照映射；不允许其他覆盖。

### 6.6 数值验收与决定

**同节点起点核查**（沿用 Round2E 的 `numeric_check`，结果为 AGREE、NOT_REPLICATED、STRUCTURE_MISMATCH 或 UNAVAILABLE_OR_FAILED）：LL 差 ≤ 0.01；关键路径差 ≤ max(0.001, 0.01 × SE)；SE 相对差 ≤ 5%。严格准则下 0.01 的 LL 容差才有判别力。

**积分核查**：最佳解的精确 LL 与打印 LL 之差 ≤ 0.01 且样本量一致，即认为 20 点积分足够；否则在同起点下加跑一次 30 点，关键路径差 ≤ 5% SE、SE 相对差 ≤ 5% 为通过。

**通过条件：**

- F1 通过：两次 E1B 都 USABLE，起点核查 AGREE，且积分核查通过。
- F2 通过：两次自由 E1 都 USABLE（SY 残差非负，其余合法性检查全部通过），起点核查 AGREE，且积分核查通过。

**决定表**（只看数值是否通过，不看 dc 的估计值或 P 值）：

| 决定 | 条件 | 家族 | 报告口径 |
|---|---|---|---|
| A | F1、F2 都通过 | 自由 E1 家族为主；E1B 家族为明示强约束的敏感性 | 主结果是自由残差下的调节；E1B 说明结论对约束是否敏感 |
| A1 | 只有 F2 通过 | 只完成自由 E1 家族 | E1B 记为数值不稳定 |
| B | 只有 F1 通过 | 只完成 E1B 家族 | 明示"在 SY 条件残差固定为 0 的强约束下"的条件估计；不作无约束调节推断；自由 E1 结果作为诊断 |
| C | 都不通过 | 不做家族 | 报告 F1、F2、F5 诊断，写明"该工作模型在本数据上没有得到稳定可用的调节估计"，本轮结束 |

**家族规则**：MI02—10 起点取同规格 MI01 的严格解；成员不可用时用 Round2E 同份 SD E0 起点修复一次；修复后仍不可用，该家族停止，不删成员、不混入不同约束或精度的成员。只有十份全部 USABLE 才合并。

### 6.7 合并与报告

- Rubin 规则，逐份取同名参数和完整参数协方差；报告估计、SE、95% 区间、P、FMI、MCSE/SE、区间宽度。固定的 SY 不进入参数向量，不给它造 SE 或 P。
- 条件斜率 b(z) = bss + dc·z，在三个冻结支持点上逐份计算后合并；对比 b(zH) − b(zL) = dc·(zH − zL)，与 dc 是同一个检验，不另计为一项发现。
- 多重性：dc 沿用 Round2E 固定 4 项的 Holm 族（SD、性别差、老大差、长子差）；只有自由残差的主家族进入；E1B、F5、F6、O1、N2 都不进入。其他分支保持缺失，不缩小族。
- E1B 的区间是"在 SY 条件残差为 0 这一约束下"的条件区间，不包含选择这一约束的不确定性，也不是对总体方差为 0 的检验。表头、方法和结论都要写明。
- F5 的三个固定点给出 MI01 上 LL 随固定值的变化（描述性剖面），以及 dc、条件斜率随固定值的变化。若 dc 的方向或区间是否跨 0 随固定值改变，结论写"依赖约束"，不挑选显著的点。
- F6 改变了样本构成，与主结果的差异不能全部归因于插补；它不证明插补相容。
- N2：三种 SE 的比值说明 dc 的 SE 来源；朴素 LR 只作描述，因为 cd ≤ 0 时 SB 尺度化不可计算。

### 6.8 各种结局怎么写

| 结局 | 可以写 | 不能写 |
|---|---|---|
| A，dc 区间跨 0 | 在自由残差的 SW 工作模型中，观测基期 SD 对亲近度变化与抑郁变化关联的调节估计为 …（区间跨 0），结论在 E1B 下相同/不同 | "没有调节"；"家内差异不起作用" |
| A，dc 区间不跨 0 | 条件于 MI 和工作模型的调节估计与区间；同时报告 Holm 调整后的 P | 因果或机制解释；把条件斜率差当作另一项发现 |
| B | 在 SY 条件残差固定为 0 的强约束下，dc 的条件估计为 …；固定为 0.02—0.08 时 …；自由残差模型在本数据上没有得到合法解 | "SY 残差在总体中为 0"；"原假设获得验证" |
| C | 该工作模型在本数据上没有得到稳定可用的调节估计，原因是 …（附诊断） | "调节为零"；"全部研究无效"（SW 与 SD E0 仍然有效） |

## 10. 对 Astra 六个问题的回答

**Q1 是否把 E1B 定义为明示强约束的敏感性规格，另批完成十份？**
值得，但要先过同节点核查（F1）。E1B 的角色取决于自由 E1 在同精度、严格收敛下能否得到稳定合法解（F2）：能，则 E1B 是敏感性；不能，则 E1B 家族是本轮唯一的调节结果，但必须写成"强约束下的条件估计"，不能作为无约束调节推断。两者都不行时不做家族。

**Q2 SY 接近 0 应怎样解释？**
现有证据最支持"弱信息"：SE 约 0.15，而 SY 在控制与 Z0 条件下的总方差只有约 0.07—0.09，数据几乎无法区分 SY 残差是 0、0.03 还是 0.08（ψSY 的 SB 差异统计量 0.0057—0.098）。样本负估计（−0.003，est/SE ≈ −0.02）完全在抽样波动之内。模型误设不能排除，但没有直接证据；三个分支同时为负不是独立证据，因为它们共用同一 Y 序列。形式识别没有问题（LL 随 ψSY 变化），问题是曲率太小。所以不能说总体为 0，也不能说约束无害；F5 直接看结论对固定值的依赖。

**Q3 其他分支的全族处理？**
原则：整族十份同一规格、同一约束、同一数值设置；不删成员；不只给失败成员加约束。具体做法应与本轮 SD 相同：先在严格收敛下重估（老大差 E0 MI06 的 SY −0.0013、SE 0.136，严格收敛可能就合法），再按 F1/F2 的逻辑判定，只有自由规格仍不合法时才用整族 SY@0 作为明示强约束的敏感性。性别差 SX、SY 同时为负且首次有病态警告，不加 `sx@0`，保持"未取得可采用估计"。另行批准，调用与时间上限在 Round2F 实测耗时后确定（第 11 节）。

**Q4 H4 的前提与映射？**
前提：SD 采用的工作规格十份全部 USABLE、数值核查通过；各资源组在支持点附近有足够人数；各组使用同一约束（不能一组固定零、一组自由）；G 已在控制列中时不重复加主效应；保留全部低阶项（SX、Z0、G、SX×Z0、SX×G、Z0×G）。系数：b_g(z) = (bss + bxg·g) + (δ + δG·g)·z，δ0 = δ，δ1 = δ + δG，正式检验 δG。方向：Z 越大越不和谐、b(z) 为负时，δ > 0 是弱化成分，δ < 0 是负向关联加强；"缓解"成分要看给定 SX 变化 s 时 Z 对 SY 的条件关系 q_g(s) = γZ + γZG·g + (δ + δG·g)·s。δ0 = −0.2、δ1 = −0.6 不是"弱化更强"。SX×Z 只操作化了变化，不代表 IX 水平的缓冲。三个资源组的 δG 为固定 3 项的 Holm 族；统计组间差异与理论方向分两栏报告。不要求 dc 显著才做 H4。

**Q5 最有信息量的有限 MI 敏感性？**
F6 完整控制样本。因为 MI 只插补基期控制（X、Y 由 FIML 处理），乘积项不在插补模型中的影响只能经由 10 个插补的控制列进入，完整控制样本（2830/3274）正好去掉这部分。再加上 dc 自己的 FMI 和 MCSE/SE。不要写成"仅缺乘积项"或"偏差必定衰减"：前者忽略了控制列插补模型与 LMS 联合结构的不一致，后者没有证据。若将来要做相容插补（如按 SX×Z0 结构的 SMC-FCS），需要从原始缺失重新运行，不在本轮。

**Q6 性能与统计可采用性？**
性能不是瓶颈：观测 E1 单次 1—2 分钟，严格收敛后预计 3—5 分钟。Round2E 的问题是统计可采用性（SY 弱信息）和数值精度（EM 准则）。本轮不加长时限，不做处理器配对；单次时限按有效秒计，待机间隙登记但不截短墙钟。
