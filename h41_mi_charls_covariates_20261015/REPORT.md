## 2. 合并结果与结论

参数用 Rubin 规则合并，完整使用每份 TECH3 协方差；两条教育差异路径用 `mitml::testConstraints(method="D1")` 联合检验，未平均 P 值。完整数据自由度采用大样本设定，插补自由度有限。[mitml 方法说明](https://search.r-project.org/CRAN/refmans/mitml/html/testConstraints.html)

| 对比 | 合并估计 | 95%条件 MI 区间 | P |
|---|---:|---:|---:|
| Z0→IY：高教育减低教育 | −0.05613 | [−0.13549, 0.02324] | 0.1657 |
| Z0→SY：高教育减低教育 | 0.04851 | [−0.14847, 0.24550] | 0.6293 |

两路径联合 **F=1.19047，df1=2，P=0.30408**，没有明确的教育组间差异证据；不能解释为证明两组完全相同。按已登记的 H4.1 共12个规格，当前保守 Bonferroni P=1；其余11个尚未完成，不能声称最终 Holm 家族校正已完成。

低、高教育组的 Z0→IY 分别为 0.00286 [−0.09079, 0.09651]、−0.05326 [−0.16095, 0.05442]；Z0→SY 分别为 0.02528 [−0.15741, 0.20798]、0.07379 [−0.16538, 0.31297]。这些是模型内条件路径；因另有 `y1 ON z0`，潜截距路径不是与2012观测抑郁的全部关联。

独立 Python 直接读取完整高精度参数表和协方差，复算8条路径、6个线性对比及 D1，结果一致。并非仅调用同一个 R 验证器。

**限制保留：**复用的是已冻结的分层 FCS 控制变量插补。其与所有交互模型的相容性并未获证明；教育有2人的插补值跨成员变化。完整估计、正确合并，不等于插补模型与 H4 的科学相容性已经全部解决。小的本模型 FMI 也不能预测未运行模型必然成功或不改变结果。

## 3. CHARLS 已落实的工作

保留上一批3,006人、3,006户、440个基期社区的连续研究队列。逐人数据只存私有目录，未上传。主调整集固定为：基期年龄、性别、初中及以上教育、城乡、婚姻/伴侣、有效报告子女数、自评健康、ADL。

| 核查 | 发现与处置 |
|---|---|
| 年龄 | 原始出生年重建3,004人；其余2人按原脚本用同次问卷 `ba004` 自报年龄。全部与已冻结队列一致。 |
| 原始与 harmonized | 年龄有1,511个非缺失不一致，其中149个 harmonized 年龄低于60；性别、教育阈值、婚姻分别15、61、12个不一致。保留比较，不把所有差异直接判为数据错误；当前用实际2011原始回答作基期来源。 |
| 主调整集缺失 | 原始性别1人、ADL20人，其余0；完整案例2,985人。不能用 harmonized 的非缺失假装原始性别完整。 |
| 家庭收入 | 缺失734人（24.42%），51个真实负值保留；扩展集使用 `asinh(收入/1000)`，不能一律把负值当缺失。 |
| 家庭消费 | 缺失451人（15.00%）；作为另一路资源敏感性，使用 `log1p`，不与收入机械同放主模型。 |
| 子女数 | 73人的 harmonized 存活子女数少于已有效报告子女数。当前使用明确命名的“有效报告子女数”作测量相关调整，不冒充总存活子女数。 |
| 地区/共同值 | 不从 ID 前两位推省份；基期省份尚未认证，不纳入主集。家庭共同值一致性检查通过。 |

缺失处理合同已保存：主集计划20份、收入/消费扩展分别40份；性别用二项模型，ADL和金额用保留支持范围的 PMM。金额先插补原变量再派生变换；家庭值按户一次抽取再映回。原观测不改，逐波 X/Y 缺失掩码保留供 FIML；如它们在插补辅助模型中临时被填值，进入 Mplus 前恢复原掩码。结构性不存在的性别差、排行差不当普通缺失插补。保留完整案例敏感性及失访/MAR限制。

下一阶段主模型按基期社区聚类；这与此前未调整试算按家庭聚类不同，必须显式记录，不能将 SE 改变归因于控制变量单独一项。无权重的模型不冒充全国代表性推断。后续潜交互/H4需要各自相容的插补方案，不自动复用这个主关联合同。

本批 **CHARLS 新插补0、新 Mplus调用0**；完成的是数据准备和方案，不是调整后实证检验。
